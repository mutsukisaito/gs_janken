# 2：制作アプリの説明（40文字程度）
コンピューターとじゃんけん対決し、どちらかが3回勝ったらゲーム終了します。

# 3：工夫した点・こだわった点
勝ち負けを視覚的にわかりやすくするため、ハートが減る仕組みを作りました。
ユーザー側もコンピューター側も、勝ち負けで表情が変わるようにしました。
ハートの残機数は変数にしているので、ハートの数を増やしやすい作りとなっています。

# 4：次回トライしたこと（または機能）
ハートの部分をHPゲージ表示にしたり、対戦相手をモンスターにしたりして
もっとバトルゲームのようにしたい。
